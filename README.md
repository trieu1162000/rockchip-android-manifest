## Usage

To set up the repository with the desired manifest for version `LAE_android11-1.0.1.xml` which includes `tinker_board-android11-1.0.1`, use the following commands:

```shell
repo init -u https://github.com/trieu1162000/rockchip-android-manifest.git -b android11-rockchip -m LAE_android11-1.0.1.xml
repo sync
